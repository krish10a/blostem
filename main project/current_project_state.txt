# Blostem MVP - Current Project State
Updated: Post Module 2 Completion

## Active Environment
- **Backend**: FastAPI (127.0.0.1:8000)
- **Frontend**: Next.js (localhost:3000)
- **Database**: local SQLite (`blostem.db`) inside `blostem-backend`
- **Vector Store**: Pinecone (`blostem-mvp-index`)

## Current Database Schema
`Prospect` Table Columns:
- `id` (Integer)
- `company_name` (String)
- `website` (String)
- `industry` (String)
- `size` (String)
- `signals` (Text) - Now stores strict JSON generated by Gemini 2.0 (signal_summary, reason_tags, raw_notes)
- `fit_score` (Float)
- `intent_score` (Float)
- `priority_score` (Float)
- `confidence_score` (Float)
- `persona_map` (Text)
- `messages` (Text)
- `sequence_plan` (Text)
- `compliance_status` (String)
- `next_action` (String)
- `created_at` (DateTime)
- `updated_at` (DateTime)

## API Endpoints Available
- `POST /prospects/`: Creates a single manual prospect requirement (requires JSON body: `company_name`, `website`, `industry`, `size`).
- `POST /prospects/upload/`: Ingests an unstructured CSV file matching the schema headers.
- `GET /prospects/`: Returns the list of saved prospects in the DB.
- `POST /prospects/{prospect_id}/generate-signals`: Triggers Gemini 2.0 API to analyze manual context and structured AI extracted signals saving it back to `signals` column.

## Frontend Checkpoint
- Home Dashboard (`page.tsx`) acts as the main Account Discovery pipeline grid.
- Interactive Components created in `blostem-ui/src/components`:
  - `ProspectIntakeForm.tsx` (Manual manual posting tool).
  - `ProspectCSVUpload.tsx` (Bulk input endpoint integration).
  - `SignalIntelligencePanel.tsx` (Dynamic AI Context window utilizing `google-generativeai`).
