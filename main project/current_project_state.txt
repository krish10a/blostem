# Current Project State: Blostem AI Marketing Automation MVP

## Overarching Goal
Build a functional MVP for enterprise B2B marketing automation using a zero-hallucination, step-by-step approach.

## Modules Status
*   **Module 1: Prospect Intake**: COMPLETED. Manual + CSV ingestion. `prospects` SQLite table defined.
*   **Module 2: Core Prospect UI Dashboard**: COMPLETED. Glassmorphic React dashboard (`page.tsx`, `ProspectTable.tsx`) running on Next.js communicating with FastAPI.
*   **Module 3: Signal Intelligence Gen AI Module**: COMPLETED. Automated background research on prospects using `gemini-2.5-flash`. Saving rigorous JSON outputs to database.
*   **Module 4: Persona Mapping**: COMPLETED. Added generation of targeted stakeholder pain points and pitch angles depending precisely on the collected Signals.
*   **Module 5: Hyper-Personalized Outreach Generation**: COMPLETED. Deeply personalized, compliance-safe sales/marketing sequences mapping exactly to the generated signals and personas.
*   **Module 6**: PENDING. (Automated sequence routing/approval pipeline or user review mechanics).

## API Endpoints (http://127.0.0.1:8000)
*   `POST /prospects/`: Create a single prospect
*   `POST /prospects/bulk`: Upload CSV of multiple prospects
*   `GET /prospects/`: List all prospects
*   `POST /prospects/{prospect_id}/signals`: Trigger Gemini Signal Intelligence task
*   `POST /prospects/{prospect_id}/map-personas`: Trigger Gemini Persona Mapping task
*   `POST /prospects/{prospect_id}/generate-outreach`: Trigger Gemini Email & LinkedIn Draft Sequence Generation

## Pydantic Output Entities
*   `SignalsOutput`: AI extraction representing Pain Points, Product Fit, Stakeholders, Intent Triggers.
*   `PersonaMapOutput`: Array of objects grouping specific executive roles (e.g., Head of Engineering) to pitch angles, objections, and pain points.
*   `OutreachGenerationOutput`: Structuring arrays of `OutreachMessage` (Emails, LinkedIn connections) assigned to each precise Persona mapped.

## Tech Stack Environment
*   **Backend**: FastAPI, SQLite (`blostem.db`), Pydantic, Uvicorn, Google GenAI SDK (`gemini-2.5-flash`).
*   **Frontend**: Next.js 15 (Turbopack), React 19, Tailwind CSS, Lucide Icons, Fetch API.

## Known Operating Mechanics
*   **Zero-Hallucination**: AI generation strictly requires parsed JSON output enforcing structured schemas (avoiding markdown bleeding).
*   **UI Integration**: Modular panel drops integrated in the user view (`SignalIntelligencePanel.tsx` -> `PersonaMappingPanel.tsx` -> `OutreachGenerationPanel.tsx`).
