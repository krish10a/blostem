# Current Project State: Blostem AI Marketing Automation MVP
# Last Updated: 2026-04-19

## Overarching Goal
Build a functional MVP for enterprise B2B marketing automation using a zero-hallucination, step-by-step approach.

## Branch
- GitHub: https://github.com/krish10a/blostem.git (branch: b1)

## Modules Status

### ✅ COMPLETED

- **Module 1: Prospect Intake** — Manual entry (ProspectIntakeForm.tsx) + CSV bulk upload (ProspectCSVUpload.tsx with fuzzy header mapping). `prospects` table in SQLite. CRUD endpoints live.
- **Module 2: Signal Intelligence** — AI-powered signal analysis via `generate_prospect_signals()` in ai_service.py using gemini-2.0-flash. Stores signal_summary, reason_tags, raw_notes. Frontend: SignalIntelligencePanel.tsx.
- **Module 3: Lead Scoring** — Weighted scoring model (fintech 30%, growth 25%, fit 20%, hiring 15%, recency 10%) via `generate_lead_score()`. Produces fit_score, intent_score, priority_score, confidence_score.
- **Module 4: Persona Mapping** — AI stakeholder mapping via `generate_persona_mapping()`. Identifies 3 decision-maker personas with pain_points, objections, pitch_angle, message_tone, CTA style. Frontend: PersonaMappingPanel.tsx.
- **Module 5: Outreach Generation** — Hyper-personalized outreach sequences via `generate_outreach_sequence()`. 3 messages/persona (email initial, follow-up, LinkedIn). Compliance rules embedded in prompt. Frontend: OutreachGenerationPanel.tsx.
- **Module 6: Compliance & Approval** — Built into outreach prompt (no separate LLM call). Auto-marks compliance_status=APPROVED. Approve button in frontend toggling outreach_status DRAFTED↔APPROVED.
- **Module 7: Sequence Builder** — Multi-day staggered timeline via `generate_sequence_timeline()`. Triggered on approval. Stores sequence_plan JSON. Frontend: SequenceTimeline.tsx with sequential day-by-day unlock logic.
- **Module 8: Sales Action Recommendation** — Auto-triggered at end of outreach generation via `generate_next_action()`. Outputs action, reason, suggested_owner, suggested_timing, priority_label. Frontend: SalesActionPanel.tsx.
- **Module 9: Analytics Dashboard** — `/prospects/analytics` endpoint. 6 stat cards + Recharts bar chart + priority leaderboard. Frontend: AnalyticsDashboard.tsx.
- **Module 10: Export & Integration** — `/prospects/export` (APPROVED only) and `/prospects/export-all` (all prospects). 3-sheet XLSX: accounts summary, sequences, compliance. Frontend export buttons in dashboard header.

## API Endpoints (http://127.0.0.1:8000)
- **CRUD**: GET /prospects/, POST /prospects/, POST /prospects/upload/, DELETE /prospects/{id}
- **AI Pipeline**: POST /prospects/{id}/generate-signals → /score → /map-personas → /generate-outreach
- **Approval**: POST /prospects/{id}/approve
- **Analytics**: GET /prospects/analytics
- **Export**: GET /prospects/export, GET /prospects/export-all

## AI Stack
- **Primary**: gemini-2.0-flash with 4-key rotation
- **Fallback**: Local Ollama (gemma2)
- **JSON Extraction**: Custom _clean_json() with markdown/regex stripping

## Tech Stack
- **Backend**: FastAPI, SQLAlchemy, SQLite, openpyxl, Google GenAI SDK
- **Frontend**: Next.js 15+, React 19, Tailwind CSS v4, Recharts, Lucide Icons
- **Source Control**: Branch `b1` on https://github.com/krish10a/blostem.git

## Constraints (Ground Truth)
- NO automated sending (manual review required)
- NO CRM integrations (XLSX handover only)
- NO browser scraping
