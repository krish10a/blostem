# Blostem MVP - Current Project State
Updated: Post Module 3 Completion (Lead Scoring & Generation Fixes)

## Active Environment
- **Backend**: FastAPI (127.0.0.1:8000)
- **Frontend**: Next.js (localhost:3000)
- **Database**: local SQLite (`blostem.db`) inside `blostem-backend`
- **Vector Store**: Pinecone (`blostem-mvp-index`)

## Current Database Schema
`Prospect` Table Columns:
- `id` (Integer)
- `company_name` (String)
- `website` (String)
- `industry` (String)
- `size` (String)
- `signals` (Text) - Now stores strict JSON generated by Gemini 2.0 (signal_summary, reason_tags, raw_notes)
- `fit_score` (Float) - Computed via rule-based backend logic
- `intent_score` (Float) - Computed via rule-based backend logic
- `priority_score` (Float) - Sum of fit and intent with weights
- `confidence_score` (Float)
- `score_explanation` (Text) - AI-generated justification for the scores
- `persona_map` (Text)
- `messages` (Text)
- `sequence_plan` (Text)
- `compliance_status` (String)
- `next_action` (String)
- `created_at` (DateTime)
- `updated_at` (DateTime)

## API Endpoints Available
- `POST /prospects/`: Creates a single manual prospect.
- `POST /prospects/upload/`: Ingests an unstructured CSV file.
- `GET /prospects/`: Returns the list of saved prospects in the DB.
- `POST /prospects/{prospect_id}/generate-signals`: Triggers Gemini 2.0 API with Google Search Grounding to extract structured signals (JSON).
- `POST /prospects/{prospect_id}/score`: Computes the rule-based Lead Score (fit, intent, priority) and generates an explanation via Gemini.
