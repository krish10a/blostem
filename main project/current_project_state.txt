# Current Project State: Blostem AI Marketing Automation MVP

## Overarching Goal
Build a functional MVP for enterprise B2B marketing automation using a zero-hallucination, step-by-step approach.

## Modules Status
*   **Module 1: Prospect Intake**: COMPLETED. Manual + CSV ingestion. `prospects` SQLite table defined.
*   **Module 2: Core Prospect UI Dashboard**: COMPLETED. Glassmorphic React dashboard (`page.tsx`) running on Next.js communicating with FastAPI.
*   **Module 3: Signal Intelligence Gen AI Module**: COMPLETED. Automated background research using `gemini-2.5-flash`. Saving structured JSON outputs to database.
*   **Module 4: Persona Mapping**: COMPLETED. AI generation of targeted stakeholder pain points and pitch angles from Signals.
*   **Module 5: Hyper-Personalized Outreach**: COMPLETED. Deeply personalized email + LinkedIn sequences per persona. Uses `[Prospect Name]` / `[Your Name]` placeholders and professional paragraph formatting.
*   **Module 6: Sequence Review & Export Pipeline**: COMPLETED. Approval workflow + professional XLSX export.
    *   Added `outreach_status` column to DB (`None` → `DRAFTED` → `APPROVED`).
    *   `POST /prospects/{id}/approve` to toggle approval status.
    *   `GET /prospects/export` streams `blostem_export.xlsx` with 2 sheets:
        - **Sheet 1 (accounts)**: One row per approved company with all scores & persona count.
        - **Sheet 2 (sequences)**: One row per outreach step (Company, Persona, Channel, Subject, Body).
    *   Frontend shows "Approve Sequence" / "Revoke Approval" button with status badge.
    *   "Export Approved (.xlsx)" button in the header bar links directly to the export endpoint.

## API Endpoints (http://127.0.0.1:8000)
*   `POST /prospects/`: Create a single prospect
*   `POST /prospects/upload/`: Upload CSV of multiple prospects
*   `GET /prospects/`: List all prospects
*   `POST /prospects/{prospect_id}/generate-signals`: Trigger Signal Intelligence
*   `POST /prospects/{prospect_id}/score`: Trigger Lead Scoring
*   `POST /prospects/{prospect_id}/map-personas`: Trigger Persona Mapping
*   `POST /prospects/{prospect_id}/generate-outreach`: Trigger Outreach Draft Generation (sets status to DRAFTED)
*   `POST /prospects/{prospect_id}/approve`: Approve or revoke approval (`{ "approve": true/false }`)
*   `GET /prospects/export`: Download `blostem_export.xlsx` for all APPROVED prospects
